# Обновление поиска от 23.09.2026

После установки программа работает **как раньше**. Всё новое либо выключено
по умолчанию, либо не меняет результатов, пока вы сами это не включите.

## Что изменилось сразу
- **Google без ключа больше не выдаёт выдуманных ссылок.** Галочка неактивна, внизу слева «Google: не настроен».
- **Итоги по источникам после каждого поиска:** какой источник сколько нашёл, какой не настроен, какой выдал ошибку.
- **Справочник сайтов:** у каждого сайта режим, приоритет, зеркала, примечание, статус последней проверки
  (работает / шаблон не задан / защита от ботов / недоступен / ошибка) и число найденного за всё время.
  Фильтр «Требуют настройки». Кнопка «Проверить» — один пробный поиск по сайту.
- **Итоги прогона по сайтам:** «Реально проверено сайтов: N из M» и список сайтов, по которым поиск не выполнялся.
- Сайты в режимах «ручная проверка» и «отключён» не опрашиваются.
- Сайты с высоким приоритетом опрашиваются первыми.
- Кнопка «Обновить адрес» при переезде сайта сохраняет шаблон поиска, старый адрес уходит в зеркала.
- Если справочник сайтов не загрузился — видна ошибка и кнопка «Повторить» (раньше было пустое место).
- Администратор видит предупреждение, если сертификату HTTPS осталось меньше двух дней.

## Что включается настройками в файле .env на сервере
| Настройка | Что даёт |
|---|---|
| `YANDEX_RESPONSE_FORMAT=compare` | Яндекс ищет по-старому, но параллельно пробует XML и пишет отчёт сравнения (виден в «Настройки и блок-лист»). Запросов к Яндексу вдвое больше. |
| `YANDEX_RESPONSE_FORMAT=xml` | Яндекс работает через XML — включать после 1–2 недель сравнения. |
| `VK_SERVICE_TOKEN=…` | Становится доступной галочка «VK: записи». |
| `VK_USER_TOKEN=…` | Становится доступной галочка «VK: видео». |
| `TORZNAB_URL=…` и `TORZNAB_API_KEY=…` | Становится доступной галочка «Торренты» (нужен агрегатор Jackett/Prowlarr на сервере). |

Без этих строк всё работает как раньше. Любую настройку можно убрать — и программа вернётся к прежнему поведению после перезапуска сервиса.
