# Запуск «Мониторинг ИС» локально на Windows

Проверьте по шагам — если что-то пойдёт не так на каком-то шаге, пришлите
мне текст ошибки, разберёмся.

## 1. Python

Откройте **PowerShell** (через меню Пуск, набрать "PowerShell") и введите:

```powershell
python --version
```

Должно показать `Python 3.11` или новее. Если пишет "команда не найдена"
или открывает Microsoft Store — Python не установлен (или установлен
неправильно). Скачайте с **python.org/downloads** (не из Microsoft
Store — там бывают проблемы с правами доступа), и при установке
**обязательно поставьте галочку "Add python.exe to PATH"** на первом
экране установщика — без неё команда `python` не будет работать в
консоли.

## 2. Распаковать проект

Распакуйте присланный архив `piracy-monitor-updated.zip` в удобную папку,
например `C:\piracy-monitor`. В PowerShell перейдите в неё:

```powershell
cd C:\piracy-monitor\piracy-monitor
```

(если после распаковки внутри ещё одна папка с тем же именем — зайдите в
неё, путь может отличаться в зависимости от того, как распаковывал
Windows).

## 3. Виртуальное окружение и зависимости

```powershell
python -m venv venv
venv\Scripts\activate
```

После этого в начале строки появится `(venv)` — значит сработало. Дальше:

```powershell
pip install -r requirements.txt
playwright install chromium
```

Вторая команда скачает браузер для функции автоматического скриншота —
займёт какое-то время (десятки-сотни МБ), это нормально, разовая
операция.

**Важно:** venv нужно активировать (`venv\Scripts\activate`) в каждой
новой сессии PowerShell, где собираетесь запускать приложение — иначе
Python не найдёт установленные библиотеки. Сам `pip install` и
`playwright install` — разовые, повторять не нужно.

## 4. Настройка (.env)

```powershell
copy .env.example .env
```

Откройте `.env` в любом текстовом редакторе (Блокнот подойдёт) и
заполните, что есть — ключи Yandex/Google Search API, Telegram. Если
ничего не заполнять — приложение всё равно запустится, просто поиск
будет работать в демо-режиме (синтетические результаты) вместо реального.

## 4а. (по желанию) Заполнить справочник «Поиск по сайтам»

Разовый скрипт — добавляет ~160 уже известных пиратских доменов
(складчины и т.п.) в справочник, чтобы не вбивать их вручную. Безопасно
запускать хоть несколько раз — дублей не создаёт (сверяет по домену).

```powershell
python -m backend.seed_pirate_sites
```

Покажет что-то вроде `Готово: добавлено 159, уже было (пропущено) 0`.
Если сервер уже был запущен в этот момент — перезапустите его после
(`Ctrl+C`, затем снова `python -m backend.app`), чтобы новые сайты
подхватились.

## 5. Запуск

```powershell
python -m backend.app
```

Должно появиться что-то вроде:
```
* Running on http://127.0.0.1:8000
```

**Windows может спросить разрешение в файрволе** ("Разрешить Python
доступ к сети?") — разрешите только для **частных сетей** (не для
публичных), этого достаточно для локальной работы.

Откройте в браузере: **http://127.0.0.1:8000**

## 6. Первый запуск — создание администратора

Сразу зайдите на **http://127.0.0.1:8000/setup** и создайте первого
пользователя с ролью администратора — своим логином и паролем. Дальше
выдавать доступ другим сотрудникам — через ссылки-приглашения в разделе
«Доступ» (уже под своим аккаунтом).

## 7. Остановка и повторный запуск

Остановить — `Ctrl+C` в окне PowerShell, где запущено (или просто закрыть
окно).

Запустить снова в другой раз:
```powershell
cd C:\piracy-monitor\piracy-monitor
venv\Scripts\activate
python -m backend.app
```

## Где хранятся данные

Всё — в папке `data\` внутри проекта (авторы, дела, зашифрованные
документы и личные данные, ключи шифрования). Эта папка — самое ценное,
что есть в проекте: копируйте её регулярно куда-то ещё (флешка, облако,
другой диск) на случай, если что-то случится с компьютером. Ключи
шифрования (`data\.documents_vault_key`, `data\.author_personal_data_key`)
лежат в этой же папке — без них зашифрованные данные не открыть, поэтому
копировать нужно **всю** папку `data\` целиком, не выборочно.

## Обновление: новая зависимость (Pillow)

Добавилась функция нанесения информационной плашки на скриншот
подтверждения хостинга — использует библиотеку Pillow. Если у вас уже
настроено окружение (venv активирован) — просто повторите:

```powershell
pip install -r requirements.txt
```

Разово, ничего больше делать не нужно — новый шрифт (кириллица для
плашки) уже лежит внутри самого проекта (`backend/assets/`), отдельно
устанавливать не требуется.
